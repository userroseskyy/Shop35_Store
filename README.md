#Shop35
Shop35 is an e-commerce web application, built with a Clean Architecture approach, focusing on backend development using C# and ASP.NET Core.

Prerequisites
Ensure you have the following software installed on your system:

Visual Studio 2022
.NET Core SDK 8
Getting Started
To use this project on GitHub, follow these steps:

Fork the project on GitHub.
Open Visual Studio and navigate to the local folder where you want to store the project.
Click on "Open a local folder" and select the location of the cloned project.
Right-click on the project file, navigate to the "Endpoint.Site" project, and select "Set as Startup Project."
Press F5 to run the project.
Requirements
Visual Studio 2022

Project Description
This project follows the Clean Architecture pattern, emphasizing separation of concerns and maintainability. It requires Visual Studio 2022 and utilizes .NET Core 8.

Running the Project
To run the project:

Fork the repository.

Open the local folder in Visual Studio.

Right-click on the "Endpoint.Site" project in Solution Explorer, select "Set as Startup Project."

Ensure the Default Project is set to "Shop35_Store.Persistence."

Run Entity Framework Migrations:

bash
Copy code
dotnet ef migrations add InitialMigration
dotnet ef database update
Press F5 to start the project.
